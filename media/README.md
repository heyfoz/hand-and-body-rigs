# Preview sources and credits

## Hands and Sentinel

The stills, GIF loops and MP4 videos were rendered from this repository's exact
GLBs using Three.js. Each loop is six seconds at 16 frames per second, at
960 × 640 pixels. Movement is driven by the existing skeleton; no geometry,
textures, skin weights or model files were changed.

- [`hands/previews/`](../hands/previews/): hand rig previews
  by Forrest Moulin. The underlying hand models retain their
  [existing source-rights notice](../hands/README.txt).
- [`bodies/sentinel/previews/`](../bodies/sentinel/previews/): Sentinel
  previews, Copyright © 2026 Forrest Moulin, under the
  [MIT License](../bodies/sentinel/LICENSE.txt).

The poses demonstrate rig movement. They are not motion-capture recordings or
verified sign-language performances. The supplied GLBs contain no animation clips.

## Vitruvian

`vitruvian-clay.png` is a neutral clay rendering of the unmodified
[`char.blend` base mesh](https://github.com/Upliner/CharMorph-Vitruvian/blob/main/char.blend),
rendered in Blender. The preview intentionally omits skin textures and hair.

Model authors: Sean Buckley and Olaf Delgado-Friedrichs; additional contributors
are credited in the upstream
[configuration and CC0 declaration](https://github.com/Upliner/CharMorph-Vitruvian/blob/main/config.yaml).
The model is CC0. Forrest Moulin also releases this preview render under
[CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
